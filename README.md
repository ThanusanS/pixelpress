# 📄 PixelPress - Free Online PDF Tools

<div align="center">

# PixelPress

### Every PDF Tool You'll Ever Need

Merge, split, compress, convert, edit, sign, protect, and watermark PDFs directly in your browser. Fast, secure, private, and completely free.

🌐 **Live Demo:** https://pdf.thanusan.dev

</div>

---

## 🚀 Features

### 📂 Organize PDFs

* Merge PDF files
* Split PDF documents
* Organize PDF pages
* Rotate PDF pages

### ✏️ Edit PDFs

* Compress PDFs
* Edit PDF content
* Add Watermarks
* Sign PDF documents
* Add Page Numbers
* Repair PDFs
* Compare PDFs
* Redact Sensitive Information
* Crop PDF Pages

### 🔄 Convert Files

* JPG to PDF
* PDF to JPG
* Word to PDF
* PDF to Word
* Excel to PDF
* PDF to Excel
* PowerPoint to PDF
* PDF to PowerPoint
* HTML to PDF
* PDF to Text

### 🔒 Security Tools

* Protect PDFs with passwords
* Unlock PDF files
* Remove PDF restrictions

### 🤖 AI Features

* AI-powered document assistance
* Smart PDF processing
* Automated optimization

## 📦 Installation

```bash
git clone https://github.com/ThanusanS/pixelpress.git

cd pixelpress

npm install

npm run dev
```

Open:

```bash
http://localhost:3000
```
